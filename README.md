# Contact Management App
A simple contact management application built with Next.js and MongoDB. It allows users to manage contact information through a clean and responsive interface.

## Features
- Add new contacts
- View the contact list
- Search contacts by first name and last name
- Filter contacts by gender
- Edit existing contacts
- Delete contacts
- Login
- Logout
- Authentication & authorization
- JWT

## Tech Stack
- Next Js
- Tailwind
- MongoDB

## Get Started
#### 1. Clone the repository
` git clone https://github.com/soheil9685/contact-list `

#### 2. Install dependencies
` npm install `

#### 3. Configure env variables
` MONGODB_URI = Your mongodb connection string `

#### 4. Run
` npm run dev `

#### 5. Live
Open localhost:3000 in your browser.
